# AUD-019-02 — Инструкция исполнителя

**Основной документ процесса:** [AUD-019-02 Shared Tests](./AUD-019-02-Shared-Tests.md)

Ознакомься с основным документом перед выполнением этой инструкции.

## Цель

Реализуй конкретные тестовые задачи, переданные Project Manager.

## Выполни

1. Возьми задачу из текущего плана Project Manager.
2. Найди соответствующий элемент в Inventory.
3. Прочитай решение эксперта и ограничения.
4. Проверь, что задача имеет достаточно информации для реализации.
5. Создай или измени тест в правильном каталоге:
   - `tests/unit/shared/`;
   - `tests/integration/shared/`.
6. Используй Jest.
7. Проверяй observable behavior, а не внутреннюю реализацию.
8. Не изменяй production-код только ради удобства тестирования.
9. Если техническое решение эксперта оказалось неверным или недостаточным, зафиксируй это в Inventory и верни элемент на повторное экспертное решение.
10. Не меняй самостоятельно смысл сценария ради получения зелёного теста.
11. Запусти соответствующие тесты.
12. Запусти необходимый typecheck.
13. После успешной реализации обнови Inventory.
14. Передай реализованный элемент на Expert Review.
15. Не отмечай элемент завершённым только потому, что появился один success-тест.

## Результат

Передай рабочий тест, результаты проверки и актуальное состояние Inventory.

Не расширяй задачу сверх текущего рабочего блока без согласования нового плана.

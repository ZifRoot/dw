## 4. Расхождения, обнаруженные исследователем

Этот блок предназначен для фиксации очевидных несовпадений между Inventory и фактическим кодом/наличием теста.

**Исследователь только фиксирует факт.** Глубокий анализ и code review выполняет эксперт.

Project Manager использует этот блок как источник рабочих задач.

| Дата | Элемент | Тестовый файл | Что заявлено в Inventory | Что очевидно обнаружено | Что не совпадает | Ответственная роль | Статус |
|---|---|---|---|---|---|---|---|
| <date> | <element> | tests/unit/shared/... | <declared> | <observed> | <mismatch> | Project Manager / Expert | OPEN |
| | | | | | | | |

Статусы расхождения:

- OPEN — исследователь обнаружил расхождение;
- PLANNED — Project Manager включил исправление в план;
- IN PROGRESS — исполнитель или эксперт работает над задачей;
- VERIFIED — исследователь подтвердил исправление;
- REPLAN — требуется новое экспертное решение.

## 5. Правила отметок

- [x] означает: соответствующий тест существует, проходит и проверяет именно эту категорию.
- [ ] означает: категория ещё не подтверждена тестом.
- N/A означает: категория не применима после экспертного анализа.
- Нельзя ставить [x], если сценарий только рассмотрен или запланирован.
- Тест-файл должен указывать на реально существующий файл.
- Expert Reviewed = [x] означает, что эксперт выполнил code review/анализ элемента и подтвердил актуальное состояние.
- Expert Review Commit должен указывать состояние исходного кода, которое проверял эксперт.
- Если Source Commit или Last Modified изменились после Expert Review, Expert Reviewed необходимо сбросить в [ ] до повторной проверки.
- VERIFIED означает, что исследователь проверил соответствие Inventory и фактического результата.

## 8. Принцип работы с Inventory

Inventory является источником фактического состояния, а не списком задач для исполнителя.

Не нужно расширять Inventory ради того, чтобы сделать его «готовым» за один проход.

Полнота Inventory достигается исследованием исходного кода.

Рабочий объём для исполнителя определяется отдельно Project Manager.

## 4. Правила отметок

- [x] означает: соответствующий тест существует, проходит и проверяет именно эту категорию.
- [ ] означает: категория применима, но тест ещё не реализован.
- N/A означает: категория для элемента не применима.
- Нельзя ставить [x], если сценарий только рассмотрен или запланирован.
- Тест-файл должен указывать на реально существующий файл.
- VERIFIED означает, что исследователь проверил соответствие Inventory исходному коду и реальным тестам.

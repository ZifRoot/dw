# AUD-019-02 — Инструкция Project Manager

**Основной документ процесса:** [AUD-019-02 Shared Tests](./AUD-019-02-Shared-Tests.md)

Ознакомься с основным документом перед выполнением этой инструкции.

## Цель

Преобразуй актуальный Inventory и экспертные решения в небольшой, выполнимый план для исполнителя и эксперта.

## Выполни

1. Прочитай незавершённые элементы Inventory.
2. Учти замечания исследователя.
3. Учти статус Expert Reviewed.
4. Если Expert Reviewed отсутствует или исходный commit/hash изменился, запланируй Expert Review.
5. После экспертной проверки планируй реализацию.
6. После реализации планируй Expert Code Review.
7. После Expert Code Review планируй Researcher Verification.
8. Учитывай стоимость ресурсов:
   - Researcher — самый дешёвый;
   - Implementer — средняя стоимость;
   - Expert — самый дорогой.
9. Не назначай эксперту работу, которую можно выполнить без экспертного участия.
10. Учитывай трудозатраты и лимит рабочего блока в токенах, времени или другой принятой единице.
11. Разбивай слишком большие задачи.
12. Не составляй план на весь Inventory — формируй ближайший ограниченный рабочий объём.
13. После изменения Inventory пересматривай план.

## Формат задачи

Каждый пункт плана должен содержать:

- приоритет;
- элемент;
- сценарий/изменение;
- роль;
- оценку объёма;
- причину;
- ожидаемый результат;
- статус.

## Результат

Оставь короткий актуальный список задач, которые исполнитель или эксперт могут реально завершить в текущем рабочем блоке.

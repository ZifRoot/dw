# AUD-019-02 — Инструкция эксперта

**Основной документ процесса:** [AUD-019-02 Shared Tests](./AUD-019-02-Shared-Tests.md)

Ознакомься с основным документом перед выполнением этой инструкции.

## Цель

Глубоко определить, что именно необходимо проверить, как это реализовать и соответствует ли существующая реализация заявленной сути.

## Выполни

1. Изучи элементы Inventory, переданные на экспертную проверку.
2. Определи observable behavior.
3. Определи применимые категории тестов.
4. Определи unit/integration подход.
5. Определи зависимости и test doubles.
6. Оцени сложность.
7. Выполни code review существующего теста или реализации, если она уже есть.
8. Проверь, соответствует ли фактический код заявленной сути элемента.
9. Проверь замечания исследователя.
10. Если обнаружено расхождение, опиши корректное техническое решение.
11. Отметь в Inventory, что элемент проверен экспертом.
12. Зафиксируй commit/hash или дату состояния исходного кода, которое было проверено.
13. Не формируй глобальный порядок задач — это задача Project Manager.

## Результат

После проверки исполнитель и Project Manager должны понимать:

- что делает элемент;
- что требуется проверить;
- как это проверить;
- насколько это сложно;
- соответствует ли существующая реализация заявленной сути.

# AUD-019-02 — Инструкция исследователя

**Основной документ процесса:** [AUD-019-02 Shared Tests](./AUD-019-02-Shared-Tests.md)

Ознакомься с основным документом перед выполнением этой инструкции.

## Цель

Поддерживай Inventory в соответствии с текущим production-кодом и наличием тестов.

## Выполни

1. Просмотри весь `packages/shared/src/`.
2. Найди релевантные модули, классы, методы, функции, фабрики и декораторы.
3. Добавь отсутствующие элементы в Inventory.
4. Удали или актуализируй элементы, которые больше не соответствуют production-коду.
5. Отметь наличие связанного тестового файла.
6. Выполни поверхностную проверку очевидного соответствия теста заявленному элементу.
7. Не определяй применимость категорий тестирования — это задача эксперта.
8. Не анализируй глубоко существующий тест и не выполняй code review.
9. Если обнаружил очевидное расхождение, добавь запись в блок «Расхождения, обнаруженные исследователем».
10. Не исправляй найденный тест.
11. Не составляй план исправления.
12. После проверки обнови статус элемента в Inventory.

## Результат

Передай актуальный Inventory и список очевидных расхождений.

Твоя задача — дешёвая и поверхностная инвентаризация. Глубокий анализ поведения и качества тестов выполняет эксперт.

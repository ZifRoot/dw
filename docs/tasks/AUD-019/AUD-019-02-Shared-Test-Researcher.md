# AUD-019-02 — Инструкция исследователя

## Цель

Поддерживай Inventory в соответствии с текущим production-кодом и фактическими тестами.

## Выполни

1. Просмотри весь `packages/shared/src/`.
2. Найди все релевантные модули, классы, методы, функции, фабрики и декораторы.
3. Добавь отсутствующие элементы в Inventory.
4. Удали или актуализируй элементы, которые больше не соответствуют production-коду.
5. Для каждого элемента определи observable behavior и применимые категории тестов.
6. Проверь наличие указанного в Inventory тестового файла.
7. Открой фактический тест и проверь, что он действительно проверяет заявленную категорию.
8. Не ставь `[x]), если тест только существует, но не проверяет соответствующее поведение.
9. Не ставь `[x]), если тест не проходит.
10. Если тест заявлен как edge, exception, failure или другая категория, проверь именно этот сценарий, а не только успешную проходку.
11. Если обнаружил расхождение между Inventory и тестом, добавь запись в блок **«Расхождения, обнаруженные исследователем»** в Inventory.
12. В записи укажи конкретный элемент, тестовый файл, фактическое поведение и заявленную в Inventory категорию.
13. Не исправляй найденный тест только потому, что обнаружил ошибку.
14. Не составляй вместо Project Manager план исправления.
15. После проверки обнови статус элемента в Inventory.
16. После выполнения работ проверь связь:
   `production code ↔ Inventory ↔ test code`.

## Результат

Передай команде актуальный Inventory и список фактических расхождений.

Твоя задача заканчивается на фиксации факта расхождения. Исправление и его приоритет определяют другие роли.
